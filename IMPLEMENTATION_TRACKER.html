"Upload Lab PDF" button on Labs page. Extraction accuracy hardened: value_str field prevents digit truncation; </> qualifiers preserved; concatenated-column prompt with Labcorp-format examples; zero-value rows included; unit-boundary truncation fix. PHI rule: patient PDFs excluded from git via .gitignore.
