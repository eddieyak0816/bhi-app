# Chat Preferences

## Communication Style
- **Minimal explanation** - Don't describe minor implementation details or steps
- Work efficiently without narrating the process
- Focus on results, not procedure

## Output Format at End of Session
1. **Files Edited** - Clear list of which files were modified
2. **Questions/Comments/Thoughts** - Any important notes, considerations, or follow-up items
3. That's it - no detailed walkthroughs or verbose summaries

## General Approach
- Use multi_replace_string_in_file for multiple independent edits (don't announce it)
- Execute tasks efficiently and autonomously
- Only ask clarifying questions if the request is genuinely ambiguous
- Assume you want results-oriented, no-nonsense assistance

## Project Context
- React 19 + TypeScript + Tailwind CSS frontend
- Supabase PostgreSQL backend
- Node.js server (express)
- BHI App - health tracking and lab results system
