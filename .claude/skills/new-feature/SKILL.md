---
name: new-feature
description: End-to-end workflow for building a new BHI feature
---

When building a new BHI feature:

1. Add the feature to `DEVELOPER_REQUIREMENTS.md` under the correct phase with a checkbox
2. Implement the feature
3. Update `IMPLEMENTATION_TRACKER.html` — mark as complete with today's date
4. Append an entry to `CHANGELOG.md` (newest first)
5. Ask: "Save this to project progress? (Yes/No)"
