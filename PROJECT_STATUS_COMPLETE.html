5. Known Issues & Blockers ⚠️

Issue 1: Infinite Loading Screen (Active)

Symptom: When switching tabs on Admin page, sometimes get stuck on "Loading…" screen

Root Cause: API request hangs without timeout. No error recovery.

Impact: User must refresh page to recover

Solution Required: Add timeout + error handling (Priority 1 above)

Issue 2: Row-Level Security Not Enabled (Critical)

Current State: RLS policies are scaffolded but DISABLED in production

Risk: All employers can see each other's data. Data isolation not working.

Impact: Legal/compliance issue. Not enterprise-ready.

Solution Required: Enable RLS (Priority 1 above)

Issue 3: Playwright E2E Tests Flaky on CI (Medium)

Current State: Tests pass locally but fail intermittently on remote runners

Impact: Can't trust CI results. Have to rerun manually.

Solution Required: Stabilize CI/CD (Priority 2 above)

Issue 4: No Error Observability (Medium)

Current State: Errors are logged to console but not tracked systematically

Impact: Don't know when things break in production until users report it

Solution Required: Add monitoring (Priority 2 above)

6. Architecture & Technical Debt

Current Architecture (Solid Foundation)

✓ React 19 + Vite (fast, modern frontend)

✓ Express.js backend (lightweight, familiar)

✓ Supabase PostgreSQL (managed database)

✓ Supabase Auth (built-in authentication)

✓ Supabase Storage (file hosting)

✓ Playwright tests (good E2E coverage)

Technical Debt to Address

1. Error Handling

Issue: No centralized error handling. Each API call is inconsistent.

Fix: Create error boundary wrapper + retry logic + timeout service

2. API Call Patterns

Issue: Admin API calls scattered throughout. No consistency.

Fix: Create API client library with standardized patterns

3. State Management

Issue: Using React useState throughout. Works but could be cleaner.

Fix: Consider Context API or lightweight state manager (not critical for POC)

4. Component Organization

Issue: Admin.tsx is large (~2800 lines). Should be split.

Fix: Extract tabs into separate components

5. Documentation

Current: Good README and scope docs. Missing: API docs, deployment guide.

Fix: Add OpenAPI/Swagger docs for backend. Add deployment playbook.
