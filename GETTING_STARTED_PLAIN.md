Getting started (plain language)

Want to check or demo the app? Do one of these:

1) Quick demo (no code)
- Open the app in a browser (ask me for the link).
- Click "Enter lab" and type a test name (example: Vitamin D) and a number.
- Watch the short videos or read a short article that appears.

2) Run a safety check (I can run this for you)
- I have a ready test that looks at the database and tells us if any private numbers are being saved.
- If you want me to run it, say: "Run the safety check now." — I will paste results and explain in simple terms.

3) If you want me to set things up in GitHub (like automatic checks)
- I can add the automatic safety check for you. To turn it on I need a safe link to the database (you can add it as a secret in GitHub or ask me to guide you).

If anything is confusing, tell me which sentence or word you don’t understand and I will make it simpler.

Note on interacting with the assistant: reply to the assistant with one-step requests. The assistant will reply with a single command or a single short question — keep responses one action at a time.
