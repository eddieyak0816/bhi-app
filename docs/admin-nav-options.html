Admin Nav — Layout Options

Current: flat horizontal tab bar that overflows. Four alternatives below — pick one to implement.

Option A
Scrollable Pill Bar
Single row of rounded pills. Scrolls horizontally when there are too many — swipe on mobile, scroll on desktop. Clean and modern. Easiest to implement (one CSS change).

Option B
Left Sidebar Navigation
Vertical sidebar with all tabs listed. More room for long labels, no overflow ever. Standard admin panel pattern (like Stripe, Supabase). Best for power users who switch tabs often.

Option C
Grouped Dropdown + Quick Tabs
A "Section" dropdown groups related tabs (Content, Scoring, People, Commerce). Selecting a section reveals a small row of sub-tabs. Reduces visual clutter at the cost of one extra click to switch sections.

Option D
Icon + Label Grid
Each tab is a small icon + short label tile. Wraps naturally into 2–3 rows. Immediately scannable — great if you access many sections. Requires choosing an emoji or icon per tab.
